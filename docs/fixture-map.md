# Карта приборов Lumina: адреса, каналы, группы

Источник правды: `web/constants.ts` → `INITIAL_FIXTURES` (конфиг проекта)
+ `docs/rig-sozvezdie.md` (физический риг, статусы приборов).
Сгенерировано 11.08.2026.

Одна 512-канальная вселенная. Две физические линии (U2 = зеркало U1):

- **ADJ / основная** — OUT 1 → A/B-свитч → проводная линия (адреса 1–191)
- **Wireless / крыло** — OUT 2 → TX-база 2.4 ГГц → RX-стики (адреса 200–449)

## Группы

**Формальных групп сейчас НЕТ**: поле `group` в `FixtureConfig` у всех
приборов = 0, включённые механизмы группы отсутствуют; в графе есть ноды
`group-activator` (GRP ACT, targetGroup), но приборы по группам не разбиты.

**Логические группы** (по линиям и ролям, используются в режиссуре):
- Диммеры 1–12 (ручные фейдеры юзера, в шоу из Lumina не управляются)
- Кулисы 33–118 (LED-парки: Backdrop/Mid/Front × L/R; backstageWash, 28.07)
- COB-блайндеры 200 (роль `overhead.cob`, пока 1 зона)
- Расчёски 250–421 (роль авансцены, моторы наклона + 10 бимов RGBW): все
  развёрнуты дисплеями внутрь сцены; сервер инвертирует MotorY и B1↔B10,
  поэтому в UI B1 остаётся крайним слева с точки зрения зрителя.
- Mini PAR 422–449 (план)
- Паучки / Фонтаны / Лазер (полка, не в шоу)

Когда будет готов фикстурный слой (этап A: профили + патч), группа станет
первоклассным объектом, а эта таблица — генерируемой из патча, а не ручной.
