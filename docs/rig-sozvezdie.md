# Площадка «Созвездие»: топология света и адресная карта

Статус: **текущий риг + подтверждённый план расширения (28.07.2026).**
Фактический состав сцены подтверждает юзер; `projects/БАЗА.json` описывает
текущий граф, но не будущие приборы и не является источником физической истины.

## Площадка

- Зал ~250 человек. Размеры (по замерам юзера): «окно» портала ~3,85 м
  (лево 384 / право 385 см), юбка сцены 746 см по дуге, высота палубы
  97–101 см, над порталом ферма. Потолок внутри сцены выше портала.
- Акустика: 2 стака (63×123 см) по краям сцены.
- Экран на сцене — управляется с этого же ПК (Resolume Arena).
- Resolume Arena: экран + 2 проектора на левую/правую стены зала (стены
  светлые — работают как доп. экраны) + перекрёстные проекции от сцены
  (часть луча на сцену, часть по диагонали на боковые стены).
- Задумка по авансцене: 4 качающиеся расчёски против зрителя для игры
  на тумане/дыме.

## Топология управления

```
ПК (Lumina server :8000, OUTPUT_MODE=wing  +  Resolume Arena)
 │
 ├─ USB ──► Китайское крыло (grandMA-совм., VID 03EB/PID 160B)
 │            │  порты: 2×DMX OUT + DMX IN + LTC + MIDI
 │            │  **U2 = ЗЕРКАЛО U1 (28.07)**: сервер шлёт одинаковый кадр
 │            │  на оба OUT; адреса не пересекаются (1–191 / 200–449),
 │            │  каждая линия читает «свои».
 │            ├─OUT 1─► A/B-свитч ◄── ADJ DMX Operator (дежурный)
 │            │            └─► Основная линия XLR (daisy-chain):
 │            │                 аналог. диммеры 1–16 (ручные фейдеры) →
 │            │                 LED-парки кулис 33–128 (РЕАКТИВ от MIDI-трек,
 │            │                 плавный фон backstageWash, 28.07) →
 │            │                 [паучки] → фонтаны (ВЫКЛ: порошка мало) →
 │            │                 лазер (СНЯТ, не используется)
 │            └─OUT 2─► Wireless TX-база (LCD, кнопки PA/ID, ~2500₽)
 │                  (( 2.4 ГГц GFSK, 126 ch AFH, 7 групп ID; стабильно,
 │                     отвалов не было ))
 │                 ┌─ RX-стик 1 ─► 2× COB-блайндера @200 (потолок сцены)
 │                 └─ RX-стик 2 ─► 4× расчёски @250/293/336/379 (авансцена)
 │
 └─ Видео: экран сцены + проекторы L/R стены + перекрёстные проекции
```

**Ключевой нюанс архитектуры:** адреса двух линий не пересекаются
(основная 1–191, wireless 200–449) — одна 512-канальная вселенная
вмещает всё, поэтому U2 = просто зеркало. «Вторая вселенная» нужна
физически (TX-база на OUT 2, чтобы не тянуть XLR к расчёскам), а не
для адресации (28.07, мастер-класс).

## Автономный режим (без ПК) — вердикт и решение

**Крыло standalone работать НЕ МОЖЕТ** (по нашему же реверсу,
tools/wing/WING_REVERSE_ENGINEERING.md):
- прошивка (34 КБ) заливается хостом в RAM при КАЖДОМ включении (boot mode
  → jump в runtime);
- без keepalive ~30 Гц от хоста крыло за ~3 с падает обратно в boot mode;
- DMX-кадры стримит хост; своей памяти сцен/процессора шоу у крыла нет.
Писать свою MCU-прошивку с движком сцен = отдельный многомесячный
embedded-проект с осциллографом — нерационально.

**Решение — A/B-переключение основной линии (внедрено 28.07):**
- A/B switch: XLR mic switcher (2-in/1-out, «для микрофона»), юзер проверил —
  DMX коммутирует исправно. Стоит в разрыве основной линии.
- **Финальная раскладка (28.07, мастер-класс):** OUT 1 → A/B (против ADJ)
  → основная линия; OUT 2 → TX-база wireless. U2 = зеркало U1
  (`send_dmx(frame, frame)` в server_v4.py) — отдельной адресации нет.
- **Шоу-режим (ПК вкл):** A/B = крыло → весь риг из Lumina: кулисные
  LED-парки играют плавный фон от MIDI-трек (провод out-2 → wash-in),
  аналоговые диммеры 1–16 — ручные фейдеры юзера.
- **Дежурный режим (ПК выкл):** A/B = ADJ (сцены на кнопках). Wireless
  молчит — и не нужен.
- **ADJ = дежурный пульт уже готов:** все сцены запрограммированы давно
  (пульту 10–15 лет, фейдеры подубиты): стробы/переливы кулисных LED,
  динамические чейсы, одноканальные диммеры на фейдерах. Ничего
  программировать заново НЕ нужно.
- Юзер хочет переставить крыло вправо (сейчас справа большая расчёска ADJ) —
  вопрос только длины кабелей/стола.
- Бонус (позже): «пульт дежурного» — простая страница в Lumina с 4 большими
  кнопками (доступна с телефона по Wi-Fi) для случая, когда ПК всё же включён.
- Перспектива (не сейчас): DMX IN крыла — можно завести выход ADJ в Lumina
  как источник (мерж/запись сцен), если драйвер это потянет.

- Фонтаны и лазер остаются в адресной карте, но физически в шоу не используются:
  фонтаны выключены, лазер снят.

**Подтверждённое расширение (учитывать в архитектуре уже сейчас):**
- Два висящих COB перестанут делить адрес: каждый получит собственный.
- Добавятся ещё два COB. Итог — **4 независимых COB** по адресам
  200/208/216/224 в физическом порядке L→R. Это не отдельный режим движка,
  а увеличение разрешения роли `overhead.cob` с 1 логической зоны до 4.
- Добавятся 4 Mini LED PAR. Точное физическое размещение ещё не выбрано.
  Они увеличат детализацию заливки на кулисах и/или сверху, поэтому софт не
  должен зашивать «ровно 6 кулис» или «ровно 4 верхних прибора»: роль,
  физический порядок и зона задаются патчем рига.
- Одновременно с подвесом — перетяжка линии по фактическому размещению.

**Резерв оборудования:**
- **Mini LED PAR 4 RGBW ×4** (7 DMX-каналов, 4×LED RGBW 4в1 по 6 Вт,
  25 Вт, угол 45°, 0,4 кг, пульт ДУ, Flicker-free). Субъективно ЯРЧЕ
  старых кулисных Euro DJ LED PAR 36 (те мрут и темнеют, но работают —
  НЕ заменяем, вешаем ВМЕСТЕ с ними).
  **Размещение: на кулисах, 2 слева + 2 справа** (потолочные линии не
  трогаем). Адреса: 422/429 слева, 436/443 справа.
  **DMX без новых свистков (решение 24.07):** RX2 переносится с потолка
  в ПРАВУЮ кулису, дальше одна проводная линия: Mini PAR R1 (436) →
  Mini PAR R2 (443) → штанга над арфиками: 4×COB (200/208/216/224,

  кулиса: Mini PAR L2 (429) → Mini PAR L1 (422). Логический порядок
  приборов L→R в софте не зависит от направления кабеля.
  В дежурном режиме молчат (ADJ видит только 192 канала) — шоу-приборы.

## Туман и пожарка

- Дым-машина 2 кВт (дешёвая, обычный плотный дым залпами) — **100%
  срабатывание пожарной сигнализации**. Не использовать в зале.
- Решение: **генератор тумана (хейзер)**. Юзер выбрал **Antari HZ-350**
  (~70 тыс.₽) — класс правильный (для зала ~250 чел: HZ-100 слабоват,
  HZ-300/350 в самый раз, с запасом по тишине/расходу). **Покупка
  ОТЛОЖЕНА**: бюджетная организация не финансирует, всё шоу-железо
  (крыло, расчёски, COB, Mini PAR, свистки) юзер покупает сам.
  Лазер до хейзера — на полке (без тумана не виден).
- Почему хейзер не будит пожарку: мелкодисперсный туман равномерной
  низкой концентрации держится под порогом оптических извещателей, в отличие
  от плотных залпов. НЕ гарантия: первый прогон — тестовый, короткий,
  в нерабочее время, с наблюдением за панелью; машину ставить в стороне
  от датчиков, поток вдоль сцены.
- Жидкость: только качественная haze-жидкость на водно-гликолевой основе
  (Antari HZL или аналог уровня Eurolite/Involight haze). Дешёвая
  fog-жидкость убивает теплообменник и даёт грязный выхлоп.

## Инструкция по подвесу (чеклист для работы на месте)

1. Повесить COB 3 и COB 4 на штангу над арфиками — к двум висящим.
2. Выставить адреса COB **строго L→R по штанге: 200, 208, 216, 224**
   (два старых переписать со 200/200).
3. RX2 (свисток с потолка) → правая кулиса.
4. Проводная цепочка: RX2 → Mini PAR R1 (436) → Mini PAR R2 (443) →
   подъём на штангу → COB 224 → 216 → 208 → 200 → спуск в левую
   кулису → Mini PAR L2 (429) → Mini PAR L1 (422) → терминатор.
5. Mini PAR: 2 слева + 2 справа на кулисах, рядом с Euro DJ
   (не заменять). Адреса: слева 422/429, справа 436/443.
6. Проверенная финальная коммутация: **OUT 1 → A/B**, **OUT 2 → wireless TX**.
7. В проекте: добавить layout `mini_par` (7ch) в `web/constants.ts` +
   4 ноды (422/429/436/443), COB — 3 ноды (208/216/224).
