## 1. Терминология (зоны крыла)

Всё ниже — только про **крыло (физ + веб-клоны)**. Компьютерная клавиатура НЕ в счёте.

| Зона | Кнопки | Обычный режим | Режим ALT |
|---|---|---|---|
| **NUM-блок** (правая цифровая группа) | 1–9, 0 | Сцены 1–10 (свитч: вкл/выкл, замещают друг друга) | Слоты 1–10 (выбор приборов) |
| **Нижний ряд** (6 кнопок) | 1–6 | Флеш-сцены 11–16 (мгновенно, на 255) | Слоты 11–16 |
| **Фейдеры 1–2** | — | Диммер- и строб-супермастеры | Каналы выбранного прибора |
| **Фейдеры 3–8** | — | Субамастера сцен 11–16 (0–255) | Каналы прибора (страницы 8) |
| **Go+ / Go−** | — | — | Страницы каналов (1–8 → 9–16 → …) |
| **STORE** | — | Режим записи сцены (мигает) | Совместим с ALT |

## 2. Иерархия выхода (приоритет сверху вниз)

```
1. BLACKOUT            — гасит всё, наивысший приоритет
2. ALT-программер      — правки оператора в поканальном режиме (всегда приоритетнее сцен)
3. Флеш-сцена (11–16)  — мгновенно, значение сцены 255, игнорирует ВСЕ фейдеры/мастера
4. Активная NUM-сцена  — свитч 1–10, одна активная (последняя заменяет)
5. 0                   — если ничего не активно
```

- Свитч-сцены (NUM 1–10) **замещают друг друга** — активна одна.
- Флеш (нижний ряд) — «вспышка» поверх текущего состояния, не ограничен положением ни своего, ни диммер-фейдера.
- Субамастер фейдера 3–8 масштабирует свою сцену (11–16) значением 0–255; над ним применяется только диммер-супермастер.

## 3. Мастера

- **Диммер-супермастер (fader1):** умножает канал диммера каждого прибора на 0..1.
  - прибор с каналом диммера (`dimmer`/`led_par_8ch`/`spider`/`mini_par` → `Int`/`Mast`) — масштабирует этот канал;
  - прибор без диммер-канала, только RGB(W) (`led_par`, `comb_rgbw`) — **механика яркости**: масштабирует RGB(W)-каналы;
  - прочие (`spark`, `laser`) — не затрагиваются.
  - Сейчас на **все** приборы; заложена возможность групп (будущее).
- **Строб-супермастер (fader2):** умножает канал строба (`led_par` off4, `led_par_8ch` off5, `spider` off3, `mini_par` off5). Без канала строба — не трогает.
- **Комбинированный канал «диммер-строб» (0–127 / 128–255)** в текущем риге НЕ встречается — все приборы с раздельными каналами. Логика (разведение на 2 мастера с растяжкой 128–254 на 255 шагов строба) закладывается в базу фикстур на будущее, не реализуется сейчас.

## 4. Режимы

- **ALT** (NUM-блок + нижний ряд): цифра = выбор слота (мультивыбор, мигание выбранных). Фейдеры 1–8 = каналы выбранного прибора от его DMX-адреса, Go+ = следующая страница из 8. Правки пишут **сразу в живой выход** (программер), высший приоритет после блекаута; сцены при этом не пишутся/не мониторятся — система слушается оператора. При выходе из ALT ничего не сбрасывается (остаётся настроенная сцена, даже не сохранённая).
- **STORE**: мигает = режим записи. Нажатие кнопки сцены → волна на панели → запись полного снепшота (сырые значения 0–255, **без мастеров**), выход из записи (STORE гаснет). ALT+STORE не взаимоисключающие.
- **CLEAR (предложение):** стирает программер (все ручные ALT-значения → 0); снимает режим STORE если активен; НЕ трогает сцены, выбор слотов и фейдеры-мастера. Отличие от blackout: blackout временно гасит выход (аварийно), Clear безвозвратно стирает ручные значения.

## 5. Сцены

- Полный снепшот DMX (сырые 0–255). **Блекаут/байпас/позиции мастеров/выбор слотов в сцены НЕ пишутся.**
- 10 сцен NUM (свитч) + 6 сцен нижнего ряда (флеш + субамастер фейдера 3–8).
- Хранятся в серверном депо (переживают рестарт), зеркалится на крыло и веб-клоны.
- При старте сервера восстанавливается последний сеанс, **все каналы = 0** (аналог блекаута), выбор слотов пуст.

## 8. Вывод по диммер/строб

- Комбинированных «диммер-строб одним каналом» приборов в текущем риге **нет** — проверено по `FIXTURE_LAYOUTS`.
- Механика диммер-супермастера: `channel` (Int/Mast) для dimmer/COB/spider/mini_par; `rgb-mechanic` для led_par/comb_rgbw; `none` для spark/laser.
- Строб: `channel` (Strob) для led_par/COB/spider/mini_par; `none` для остальных.
- В базе фикстур заложить поле `dimmer:{mode}` и `strobe:{mode}` с поддержкой `combined` (0–127/128–255) на будущее.

## 9. Решения (утверждено юзером 15.08)

1. Терминология зон утверждена: NUM-блок (правая цифровая группа 1–9,0) + нижний ряд (6 кнопок 1–6); отдельного верхнего ряда цифр нет.
2. Раскладка слотов (табл. 6) утверждена без изменений: 0=PAR-свет, 1=COB×2, 2=кулисы×6, 3–6=расчёски ×4, 7–8=Mini PAR L/R, 9 и 11=резервы COB 3–4, 12–14=пауки (полка), 15=фонтаны, 16=лазер.
3. Механика яркости для RGB-приборов без диммер-канала (led_par, comb_rgbw): супермастер масштабирует RGB(W)-каналы. Утверждено.
4. NUM-сцены без фейдера (свитч 0/100%, через диммер); флеш — 255 без мастеров. Утверждено.
5. CLEAR = стереть программер (ALT-значения → 0) + снять STORE; сцены/выбор/мастера не трогает; blackout не дублирует. Утверждено.
6. Старт сервера: восстановление последнего сеанса, все каналы = 0 (аналог блекаута), выбор слотов пуст. Утверждено.
7. Блекаут на крыле = Pause (id 118), на вебе — кнопка; клавиатура не в счёте. Утверждено.
